
# Learning Log - Mini Project 3

## What did I learn during the process of creating this project? 
While I was developing this third mini project, I gained a greater understanding of how to create a practical, data-driven website. In particular, I discovered how to integrate the MBTA API to obtain information about public transit across the city of Boston, as well as use the MapBox API for geographic location data into an effortless process. Furthermore, I was able to obtain practical expertise with multiple APIs and requests using HTTP. I was also able to improve my formatting skills, considering that I had to organize different variables throughout the creation of the process, for it to look visually appealing and for the outputs to be presented in an understandable, user-friendly format. By creating a basic web interface, I was able to improve my comprehension of both frontend, as well as backend interactions, and witness how each small change made in VSCode was later reflected and made visible in the website. All of these interactions made it easier for me to see how applications like Python can be also utilized when creating interactive apps that allow users to interact with real-world issues, such as raising accessibility awareness across different stops and areas of Boston’s public transportation system. 

## How did AI tools help me during the development of the project.
During the development of this mini project, I used Claude to overcome obstacles and speed up the creation process of the website. Some of the main problems I encountered while building the code included API integration, as well as addressing circumstances where no results appeared on the frontend. AI tools helped me spot minor, yet crucial issues that were difficult to identify once all the code was created, such as fixing parameter structures. AI also assisted me in improving my website’s aesthetic appeal. I changed the backdrop color scheme to blue and used various shades of the color palette since I wanted to page to represent my personality. As a result of these choices, AI assisted me in identifying and creating many combinations that would look good once users logged on to it. The AI tool I used for this mini project served as a support network that allowed me to be very efficient, considering that it helped me to not get stuck on minor technical errors. It helped me improve the structure of my code and provided me with detailed explanations for debugging issues when I didn’t understand what section of my code was incorrect.
