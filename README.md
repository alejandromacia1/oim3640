## My Projects: 
- [First Project] (https://github.com/alejandromacia1/oim3640/tree/main/projects/miniproject_1) 

My project is an interactive Python command-line restaurant guide and menu simulation system that is designed to personalize the dining experience of an individual, based on its user preferences. Hence, it intends to simulate a real restaurant ordering process. During the first part of the process, users begin by entering their preferred budget level, cuisine type, and desired restaurant vibe (atmosphere). After that, the system generates a tailored restaurant recommendation based on user inputs and the program presents a customized menu that offers two entree options, two main course options, as well as two dessert options. The prices of the menus are adjusted based on a budget pricing multiplier, simulating the different dining experiences and their corresponding price levels. 

- [Second Project] (https://github.com/alejandromacia1/oim3640/tree/main/projects/miniproject_2)

My second mini project is a dialogue processing system that analyzes and retrieves speech from the novel, titled Wuthering Heights and its two protagonists, Catherine and Heathcliff. In order to deliver better quantitative insights into the two major characters' responsibilities throughout the novel, it is intended to measure and contrast their dialogue dominance. The application imports the entire book, divides it into the different chapters, then uses quoting patterns to identify dialogue portions. Each conversation line is subsequently assigned to each of the protagonists using a speaker detection process. Accordingly, the approach tracks how each of the protagonist's participation changes throughout the novel's sections and evaluates a number of measures, including their most common words and the total of words spoken. Overall, the assignment mimics an assessment of literature tool that converts written material into quantifiable insights.

- [Third Project] (https://github.com/alejandromacia1/oim3640/tree/main/projects/miniproject_3)

My project is a Python-built web program that assists users to locate and evaluate the accessibility of the closest public transit spots across Boston and its surrounding neighborhoods. When users enter the website, they can input their location/area of interest and the program uses the MapBox API to determine their location within the boundaries of the city. With this information, the program queries the MBTA API to determine the nearest transit stop they could take. On top of this, the application highlights whether the corresponding stop is wheelchair accessible or not. The purpose of this project is to give users an easy-to-use interface so they can decide how best to move around the city.
